# Daily Overlay / Shinp Studio

Android 用の小さな利用時間表示と半透明のフローティングメモ。Java / Android ネイティブ UI。ネット接続権限なし、画面キャプチャなし、AccessibilityService なし。API 30 以上。

## 使い方
1. アプリを起動して「重ねて表示」「使用状況へのアクセス」「通知」を許可する。
2. 「オーバーレイ開始 / 設定反映」。SNS・ゲーム・その他を1行で、OSのステータスバー直下に表示する。30秒ごとに更新。時間は端末のローカル日付で区切る。
3. 時間表示をタップすると、利用時間帯（開始〜終了、アプリ名、利用時間）とアプリ別集計が開く。左右の日付ボタンで過去の日を選択。閉じるボタンまたは上の時間表示で収納。
4. メモは設定画面で入力・保存。メモ上部をドラッグして移動、右下をドラッグしてサイズ変更。「固定」を押すとタップ透過。固定解除は通知または設定画面から。色・不透明度・文字サイズ（12〜26sp、初期値16sp）・枠サイズを設定可能。
5. 「オーバーレイ終了」または通知の「終了」で両方を消す。各表示は設定で独立して有効/無効にできる。

## ビルド
JDK 17、Gradle 8.9、Android SDK Platform 35 / Build Tools 35.0.0 が必要。Gradle wrapper は同梱していない。

```powershell
gradle assembleDebug
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
```

Android Studio でこのディレクトリを開いて同期・Run する方法も可。GitHub Actions (`.github/workflows/android.yml`) は集計テスト、assembleDebug、lintDebug を実行して `daily-overlay-debug-apk` をアップロードする。CI とローカルで debug 署名が違う場合、上書きインストールは不可。

## 集計の仕様と制約
- Android UsageEvents に基づく単一フォアグラウンドアプリの推定。日付またぎ、画面消灯、ロック、アプリ切り替え、終了イベントを処理。ランチャーから起動できるアプリのみ対象で、ホーム画面・自身は除外。既定分類は Android のカテゴリや既知のSNS/ボードゲーム名を利用。設定から修正可能。
- マルチウィンドウ、PiP、バックグラウンド再生は実際の注視時間を計測できない。履歴は OS の保持期間と権限に依存し、アンインストール済みアプリは対象外。メモ・設定は SharedPreferences に保存。履歴はローカルで都度取得し、外部送信しない。
- 通常のアプリオーバーレイはシステムの時計やステータスバー、キーボードより手前には描画できない。一部の保護画面でも非表示になる。固定時のウィンドウ不透明度は最大0.8に制限。画面上端に時間表示とメモが重ならないように配置する。
- 端末再起動後の自動起動なし。再起動後はアプリを起動して開始。
